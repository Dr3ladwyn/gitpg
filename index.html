Как нейронные сети помогли мне в моей работе по анализу социально-экономических условий жизни молодежи

Опыт использования GitHub Copilot, Augment, ChatGPT и других моделей в дипломном проекте

Data Science

Вступление

Когда я начал писать дипломную работу по анализу социально-экономических условий жизни молодежи в регионах Сибирского федерального округа, я сразу понял, что проект будет объемным. В работе необходимо было объединить данные Росстата, нормализовать показатели, рассчитать индекс благоприятности и построить интерактивную карту. Я написал программу на Python и постепенно начал использовать GitHub Copilot, а позже подключил другие инструменты: расширение Augment, Copilot, модели ChatGPT 5.1, Codex и Sonnet 4.5.

Все они по-разному помогали ускорить техническую часть, подсказывали решения и избавляли от рутины.

Моя дипломная работа и задачи

Целью моей работы был анализ социально-экономических условий для молодежи с использованием кластеризации и построение собственного индекса благоприятности для регионов Сибирского федерального округа.

Анализ проводился на основе четырех показателей:
  • численность молодежи;
  • уровень образования;
  • реальная заработная плата;
  • уровень безработицы.

Я взял данные из Росстата и объединил их в один массив данных. После этого я провел нормализацию, рассчитал интегральный показатель и составил прогнозы. В итоге я создал интерактивную HTML-карту регионов Сибирского федерального округа.

Код получился большим, поэтому я активно использовал GitHub Copilot в VS Code.

Как GitHub Copilot помог мне в программировании

1. Автоматические подсказки и шаблоны

Когда я начинал писать функции, Copilot часто предлагал рабочие версии кода.

Например, я писал:

def normalize_column(self, series):

И он выдавал готовый фрагмент:

denom = series.max() - series.min()
if denom == 0:
    return pd.Series(0.5, index=series.index)
return (series - series.min()) / denom

Пример хорошего и плохого поставления цели для нейросети

Поскольку в своей работе я использовал нейронные сети, в статье я хотел привести конкретный пример того, как формулировка запроса влияет на результат.

Плохая постановка задачи

"Создайте красивый html-файл, который отображает информацию из таблицы на карте"

Этот запрос слишком общий. Непонятно, какие данные использовать, какая нужна карта, как должна выглядеть визуализация, какие индикаторы отображать и так далее. Нейронная сеть выдает абстрактный код, который совершенно не соответствует моей задаче.

Хорошая задача

Создай отдельный HTML файл для визуализации данных из таблицы на интерактивной карте регионов СФО. Требования:

Структура файла: самостоятельный HTML файл, встроенные CSS и JavaScript, адаптивная верстка.

Источник данных: использовать таблицу self.df_combined, включить годы 2014–2034, отображать регион, год, индекс, молодежь, зарплаты, образование, безработицу.

Работа карты: интерактивные регионы СФО, цветовая заливка по индексу благоприятности, переключение по годам, всплывающие подсказки.

Дизайн: современный интерфейс, легенда цвета, отметка прогнозных значений.

Технические детали: сохранить как output/table_map_visualization.html, разрешено использовать Plotly, Leaflet или D3.js, файл должен открываться в браузере без зависимостей.

Постановка задачи таким образом уже дает полноценный и подходящий результат. В нем описывается контекст задачи, данные, формат вывода и технические детали.

Вайбкодинг

В дополнение к Copilot я использовал инструмент Augment Code. Он полезен тем, что анализирует весь проект, а не отдельные функции.

В моем случае это помогло:

  • найти повторяющиеся участки кода;
  • предложить провести рефакторинг;
  • выделить потенциальные ошибки в логике;
  • улучшить читаемость функций;
  • предложить оптимизацию циклов и обработки данных.

Например, в Augment Code предлагалось объединить похожие блоки нормализации и перенести часть логики в универсальную функцию. Это сократило объем кода и упростило его обслуживание.

Как я использовал модели ChatGPT 5.1, Codex и Sonnet 4.5

Помимо использования Copilot agent, у меня был опыт использования нескольких языковых моделей для отдельных задач.

1. ChatGPT 5.1

Используется для объяснения сложных вещей простым языком.

Примеры использования:
  • как правильно рассчитать тренды при прогнозировании;
  • каков наилучший способ визуализации индексов на карте?;
  • как переписать код, чтобы он был более удобочитаемым.

ChatGPT 5.1 предоставил наиболее понятные и структурированные ответы.

2. Codex

Codex помог в части кода. Он был лучшим в Python и pandas.

Результаты:
  • ускорил написание функций;
  • исправлены ошибки с индексами фреймов данных;
  • получил примеры быстрой векторизации вместо циклов.

3. Sonnet 4.5

Sonnet 4.5 был полезен в тех местах, где нужно было тщательно переработать текст:

  • формализовать описание методологии;
  • переписать разделы диплома в более понятной форме;
  • подготовить пояснение для визуализации.

Sonnet предоставляет мягкие и аккуратные формулировки без перегрузки, а также хорошо подходит для программирования.

Слабые места нейросети

Несмотря на удобство, ошибки тоже были.

  1. Вымышленные данные и галлюцинации. Некоторые модели предлагали поля, которых не было в данных.
  2. Упрощения в математике. При прогнозировании модели иногда давали слишком простые формулы, которые невозможно было применить к данным Росстата.
  3. Избыточные циклы. При обработке данных модели часто предлагали громоздкие циклы вместо векторизации. Вот почему я проверил все подсказки вручную.

Проверка результатов

Чтобы убедиться, что проект работает корректно, я:

  • проверил промежуточные значения;
  • сверил их с таблицами Росстата;
  • протестировал каждую функцию отдельно;
  • пробовал разные способы нормализации;
  • вручную отредактировал фрагменты, где подсказки были слишком простыми.

Мое мнение об инструментах

На что можно положиться

  • при создании простых функций;
  • при генерации однотипного кода;
  • при анализе синтаксических ошибок и подсказок;
  • при объяснении ошибок.

Где лучше не полагаться

  • на точные математические модели;
  • при расчете индексов;
  • при прогнозировании;
  • при определении логики проекта.

Буду ли я использовать их в дальнейшем? Да. Они экономят время, но требуют проверки. Нейронные сети помогают, но не заменяют разработчика.

Вывод

Работая над своим дипломом по анализу социально-экономических условий для молодежи, я убедился, что модели GitHub Copilot, Augment Code и ChatGPT 5.1, Codex и Sonnet 4.5 могут значительно ускорить и упростить разработку. Они помогают вам написать код, оптимизировать проект и объясняют сложные моменты.

Но любую подсказку нужно проверять, потому что ответственность за результат остается за человеком.

Мой опыт показал, что нейронные сети лучше всего работают как вспомогательный инструмент. Именно такое сочетание дает качественный результат и делает работу более комфортной.
